# Demo videos for recommended tests

Drop your edited demo files in this folder.

## Naming

Use the **test code** as the filename:

| File name | Test |
|-----------|------|
| `PTA.mp4` | Pure Tone Audiometry |
| `TYMP.mp3` | Tympanometry |
| `SPEECH.mp3` | Speech Audiometry |
| `OAE.mp3` | Otoacoustic Emissions |
| `ABR.mp3` | Auditory Brainstem Response |
| `VNG.mp3` | Balance / VNG |
| `OTOSCOPY.mp3` | Ear examination |
| `TINN_ASSESS.mp3` | Tinnitus assessment |
| `SLP_EVAL.mp3` | Speech-Language Evaluation |
| `VOICE_EVAL.mp3` | Voice Assessment |
| `FLUENCY_EVAL.mp3` | Fluency Assessment |
| `ARTIC_EVAL.mp3` | Speech clarity assessment |
| `SWALLOW_ASSESS.mp3` | Swallowing assessment |

## Format

Configured for **`.mp3`**. If you later use **`.mp4`** / **`.webm`**, rename the file and update `file` in `src/data/testDemoVideos.ts`.

After uploading, refresh the Recommended tests page — the player appears under each test’s explanation.
